# To Do 

To setup this project:

- Firstly clone this repo by clicking Code button at the right of Add File button which will give 3 options: use SSH link
- Open any terminal, write git clone and the link from SSH
-After successful clone, run npm install to install all the dependencies
-Finally run npm run dev

# Add To Do 

- There is a input field where you can write all the todos and click on Add button at the right side of it

# List To Do

- The Added To do will be store in list below the input field.

# Edit To Do

- On Clicking the edit icon the same input with the item we want to edit gets triggered and on clicking Edit button the item is edited.

# Delete To Do

- On clicking Delete icon, a confirmation modal will open asking if we want to delete the item and on clicking confirm the item will be deleted.

# Complete-Incomplete To Do 

- On clicking the checkbox the item will be marked as completed, it will be crossed out.

# Filter-To Do

- There is dropdown to filter through All Task, Completed Task and Incomplete Task

# Reorder Task

- on dragging through the dotted type of icon you can Reorder Task. Ensure you have minimum 3 task.

# Right Menu

- On Right clicking anywhere in the list item till the left of delete icon, you will see a context menu where you can Edit, Delete and Mark as incomplete if completed and complete if incomplete.
